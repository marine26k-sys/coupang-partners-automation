# 살림셀렉트 성과·비교·콘텐츠 운영

## 통계
- `growth_analytics.py`: 쿠팡 4종 리포트 최근 7일(어제까지) 수집, `artifacts/analytics` 권한600 비공개 저장. 과거 식별자 없는 유입은 미분류, 누락 지표는 미확인. 리포트 수수료는 확정 입금액으로 부르지 않는다.
- `content_tools.py insights`: Threads 읽기 전용 지표 수집. 학습은 발행24시간 이후·그룹5글·조회100 이상, 두 주제 이상 표본 확보 후 최대10점 가중치만 사용. 강한 가격 근거·예산 우선순위를 대체하지 않는다. 시간대는 자동 변경하지 않는다.
- `browser-metrics.json`: 토스·네이버에서 실제 보이는 지표만 provider/date/scope/capturedAt과 저장한다. 계정 전체 통계를 채널별로 임의 분해하지 않는다. 토스 계정 합계와 쿠팡 합계, 기간이 다른 지표는 더하지 않는다. 초기 등록 화면의 placeholder 0을 수집하지 않는다.
- 쿠팡 채널은 유효한 등록 subId를 사용한다. threads_auto=Threads, sallim_select=홈페이지, blog_auto=블로그. 계정에서 등록을 확인하기 전 새로운 식별자를 임의 생성하지 않는다.

## 비교
- `artifacts/comparison-offers.json`: service/name/brand/model/variant/quantity/unit/price/shipping/url/checkedAt/verified/ownerLinkVerified.
- 실제 옵션과 본인 제휴 링크를 확인한 경우에만 verified 플래그를 켠다. 쿠팡 링크는 itemId/vendorItemId를 보존한다.
- 브랜드·모델·규격·색상·수량·단위가 일치하고 6시간 이내인 경우에만 공개한다. 사진만 비슷하면 비교하지 않는다.
- 배송비 미확인은 null. 0으로 추정하지 않는다. 쿠폰·배송 조건은 구매 페이지에서 확인하도록 안내한다.
- 블로그 작업 시 토스 신규상품에 맞는 쿠팡 동일 옵션을 확인할 수 있으면 이 파일을 갱신한다. 없으면 빈 비교 결과가 정상이다. 잘못된 한 항목 때문에 다른 항목까지 임의 공개하지 않는다.

## 이상 감지
- 비교 가능한 이전 카테고리의 전체 상품 수 대비60% 미만이면 공개 목록 교체 보류.
- 동일 판매 옵션의 이전 날짜 대비 가격이 절반 미만 또는2배 초과면 추천·자동발행 후보 제외. 원자료 확인 필요를 표시한다. 이상값은 가격 이력에 넣지 않는다.
- 이미지 정보 없는 상품은 자동 게시 검수에서 보류한다. 이미지 자체·선택 옵션 일치는 브라우저 최종 확인이 필요하다.

## 콘텐츠
- `content_packages.py`: 6시간 이내 신선한 상품으로 용도별3만원 예산 묶음 초안 생성. 상품 표시가격 합계이며 배송비 포함 결제총액으로 표현하지 않는다. 결과는 draft_only이며 자동 공개하지 않는다.
- `content_packages.py --video`: 12초1080×1920 H264 영상. 실제 공식 상품 사진 전체를 보존하고 가짜 경험·긴급성·최저가 표현을 넣지 않는다. 제휴 고지 포함. 영상/원본은 공개 저장소로 올리지 않는다.
- 묶음 글은 상품별 링크/구성/가격시각과 사진을 확인한 뒤 별도 다상품 검수가 필요하다. 기존 단일상품 대기열에 억지로 넣지 않는다.
- 정규 예약은 성과 수집·홈페이지 갱신·묶음 초안을 순차 실행한다. 한 단계 실패가 이미 발행한 글을 다시 발행하게 만들지 않는다.
