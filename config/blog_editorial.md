# 살림셀렉트 블로그 발행 기준

대상: https://blog.naver.com/sallim-select
카테고리: 상품 용도에 맞춰 주방·수납 / 생활·청소 / 욕실·세탁 / 홈·인테리어 중 선택. 발행 창에서 실제 이름을 확인한다.
한국시간 10시 쿠팡 1건, 19시 토스 1건. 기존 Threads 예약을 이 작업에서 실행하지 않는다.

- 제목은 상품 유형과 구매 기준을 간결하게 연결한다. 낚시성 제목, 이모지, 느낌표는 쓰지 않는다.
- 본문은 담백한 해요체. 도입은 1~2줄, 소제목은 굵게, 각 설명은 한 문장씩 짧은 문단으로 나눠 빈 줄을 둔다. 구매 전 확인점은 · 기호로 2~3항목 정리한다.
- 소제목 앞에 🧺 📌 🔎 중 하나씩, 글 전체 3개 이내로 구분용 이모지를 사용한다. 본문 문장마다 이모지를 붙이지 않는다.
- 의미 있는 소제목 3개로 구매 전 확인할 점을 설명한다. 같은 설명을 반복해 분량을 늘리지 않는다.
- 적합한 상황과 적합하지 않은 상황을 구분한다. 상품명에 없는 규격·재질·효능을 추정하지 않는다.
- 직접 사용하거나 구매한 경험을 꾸며내지 않는다. 할인율·인기·최저가를 근거 없이 쓰지 않는다.
- 쿠팡 첫 문단: ※ 이 게시물은 쿠팡파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
- 토스 첫 문단: ※ 이 포스팅은 토스쇼핑 쉐어링크 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
- 해당 서비스의 본인 계정에서 발급된 제휴 링크만 본문에 넣는다.
- 가격을 쓰려면 옵션과 확인 시각을 함께 쓰고, 최종 결제금액은 구매화면에서 확인하도록 안내한다.
- 사진은 정확한 상품 옵션의 공식 사진 1개. 모든 본문과 링크가 끝난 뒤 맨 아래 빈 문단에 넣는다.
- 편집기에서 문장 중간 클릭 후 사진 삽입 금지. 본문을 다 입력한 후 끝의 빈 문단에서 삽입한다.
- 사진 미확보, 연결 실패, 품절, 스팸 차단 시 공개 발행하지 않는다.
- 공개 발행 전에 온전한 문장·제휴 링크·사진 하단 배치를 확인하고, 저장 후 공개 글에서 다시 확인한다.
- 기존 발행 이력과 같은 상품 또는 같은 시간대 중복 발행 금지. 불명확한 결과는 재발행 대신 확인한다.
- 브라우저 로그인 유지가 필요하다. 인증·약관·CAPTCHA는 사용자 조치를 요청한다.

## 정보 구성 보완
고른 이유 → 확인된 핵심 구성 → 구매 전 확인점 → 본인 제휴 링크 순서로 연결한다.
소제목과 핵심 옵션만 굵게 표시하고 문단은 1~2문장으로 나눈다. 인기 근거는 서비스명·조회 날짜와 함께 쓴다.
순위를 통합 판매순위로 확대 해석하지 않으며, 실제 조회 목록의 순위라고 명시한다. 할인율은 실제 기준가격의 근거가 있을 때만 쓴다.


## 예산을 기준으로 한 기획
- 오전에는 1만원 이하, 오후에는 3만원 이하의 생활·주방 상품을 우선 검토한다. 적합한 상품이 없으면 기존 검증 상품으로 대체한다.
- 예산보다 사용 목적·구성·보관 공간의 적합성이 먼저다. 가격만 보고 불필요한 구매를 권하지 않는다.
- 현재 조회 가격과 구성 확인이 된 경우에만 제목에 예산을 쓴다. 배송비·쿠폰·옵션에 따라 최종 가격이 달라짐을 안내한다.
- ‘만원 이하 주방 소모품’, ‘3만원 안쪽 수납 정리’처럼 예산과 용도를 묶되, 없는 할인율·마감 시간·사용 경험을 만들지 않는다.


## 발행 직전 품질 확인
- 제목·본문의 수량, 크기, 용량은 해당 상품·옵션의 확인된 정보와 대조한다. 확인되지 않은 수치는 삭제하거나 발행을 보류한다.
- 동일 문장 반복과 직전 글의 상투적인 끝맺음을 확인하고 수정한다. 광고 고지는 반복 검사에서 제외한다.
- 본인 제휴 링크, 서비스별 광고 고지, 이미지, 상품 옵션과 가격 확인 시각을 최종 확인한다. 가격은 6시간 이내 자료만 사용하고 오래됐으면 재조회하거나 가격을 생략한다.
- 치수를 재라는 일반 조언과 실제 제품 치수 주장을 구분한다. 문자열 일치만으로 사실이 검증됐다고 판단하지 않는다.


## 필수 발행 대기열
1. `blog_queue.py`의 prepare 입력 형식으로 비공개 JSON을 만든다. provider, product(name/id/affiliateUrl/option/image/imageVerifiedByOwner/checkedAt), title, sections(heading/body 3개). 토스는 linkVerifiedByOwner=true가 필수다. verifiedEvidence에는 실제 확인한 사양만 넣는다. 이미지와 링크 확인 플래그는 실제 확인 후 설정한다.
2. `.venv/bin/python blog_queue.py enqueue --input <보호된 JSON> --slot YYYY-MM-DD-10` (토스는 -19). 검수 실패 시 공개 발행하지 않는다. 입력 파일은 권한 600으로 저장한다.
3. `.venv/bin/python blog_queue.py claim --id <ID>`로 발행 시작한다. 반환된 보호 파일의 html/text만 네이버 편집기에 넣고 정확한 공식 사진을 맨 아래 업로드한다.
4. 브라우저에서 제목·문장·링크·광고 고지·사진 위치를 검토하고 발행한다. 공개 글을 확인한 뒤 `blog_queue.py finish --id <ID> --url https://blog.naver.com/sallim-select/<글번호>`로 기록한다.
5. publishing 상태로 남은 항목은 결과 불확실 상태다. 같은 상품이나 시간대를 재발행하지 말고 공개 글부터 확인한다. 기존 publication-tests.json도 반드시 대조한다.

쿠팡 블로그 제휴 링크 발급 시 등록된 채널 ID `sallimblog`를 사용한다. 기존 링크를 단순 변형하지 말고 딥링크 API로 새로 발급한다.


## 상황별 비교 콘텐츠
- 먼저 공간·사용 목적·필요 수량을 설명하고, 확인한 상품명·구성·조회 가격을 후보별로 나눠 제시한다.
- 수량이 명확한 상품만 수량당 가격을 계산한다. 원 단위 반올림이며 배송비·쿠폰은 미포함이라고 안내한다. 서로 다른 크기·형태의 단가로 성능이나 가성비 순위를 만들지 않는다.
- 구매를 미뤄도 되는 조건을 함께 쓴다. 확인되지 않은 장단점, 내구성, 사용감은 만들지 않는다.
- `comparison_editorial.py`가 생성한 `artifacts/content-packages/pantry-bundle.json`은 미발행 검토용이다. 각 상품 사진과 옵션·가격을 다시 확인하고 다상품 검수를 거쳐야 하며 단일상품 대기열 검수를 우회하지 않는다. 기존 예약 발행 수를 늘리지 않는다.

## 모바일 문단 기준
- 본문은 작은 글씨(HTML 14px, 네이버 변환 시 13 크기), 소제목은 16 크기 굵게 사용한다.
- 문단 사이에는 실제 빈 문단 한 줄을 넣는다. CSS 여백만으로 처리하지 않는다.
- 소제목은 12자 안팎으로 짧게 써서 모바일에서 한두 글자만 다음 줄로 넘어가지 않게 한다.

- 칫솔 상품은 사용자 요청으로 선정 제외한다. 삭제한 칫솔 글은 다시 발행하지 않는다.
- 최근 발행 주제를 확인해 같은 주방·수납 주제로만 이어지지 않게 생활·청소, 욕실·세탁, 홈·인테리어 후보도 검토한다.

카테고리 확인 번호: 주방·수납=1, 생활·청소=13, 욕실·세탁=14, 홈·인테리어=15. 발행 창의 이름을 함께 대조한다.
